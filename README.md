# Gestionnaire de Tâches Collaboratif

## 📝 Description
Application web développée avec Django permettant de gérer des projets et des tâches en équipe.

## 🛠️ Technologies Utilisées
* **Back-end :** Python, Django
* **Base de données :** PostgreSQL
* **Front-end :** HTML5, CSS3, JavaScript (Vanilla) - *à venir*

## ⚙️ Installation en local (Pour les recruteurs ou autres développeurs)
(C'est ici que tu montres que tu maîtrises ton environnement. Explique les étapes pour faire tourner le projet sur une nouvelle machine)
1. Cloner le dépôt : `git clone ...`
2. Créer et activer l'environnement virtuel : `python -m venv venv` puis `venv\Scripts\activate`
3. Installer les dépendances : `pip install -r requirements.txt`
4. Configurer PostgreSQL...
5. Lancer les migrations : `python manage.py migrate`
6. Lancer le serveur : `python manage.py runserver`
